# MathGene

## 📖 Overview
Have you ever wondered why brown eyes are the most commmon eye color? In this project biology, mathematics and programing are used in order to investigate an interesting question:
**Can mathematics predict how an allele will spread in a population?** Alongside carefully explaining the basic biology concepts, this project also studies the mathematical model by visually
presenting data.

## 🛠️ Technologies Used
- **Visual Studio Code**
- **Python**
- **Jupyter Notebook**
